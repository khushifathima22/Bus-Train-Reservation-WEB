# Bus & Train Reservation System

A web-based Bus and Train Reservation System developed using HTML, CSS, and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript
- Visual Studio Code

## Features

- User Login
- Bus and Train Route Search
- Seat Selection
- Fare Calculation
- Ticket Booking
- Payment Interface
- Booking Confirmation
- Booking History
- Responsive User Interface

## Project Description

This project was developed as an academic web development project to provide a simple and user-friendly platform for searching routes, selecting seats, calculating fares, and managing bus and train reservations.

## Project Modules

- Login
- Route Search
- Seat Selection
- Fare Calculation
- Booking
- Payment
- Booking Confirmation
